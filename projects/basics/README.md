# Basics

Small standalone Python scripts used for learning/practice — not tied to any AI service.

## Files

- `f01.py` — calculates the area of a rectangle from user input.
- `factorial.py` — placeholder, currently empty.
- `pdf2word.py` — Streamlit app that converts PDF ↔ Word (`.docx`) files using `pdf2docx`, `python-docx`, and `fpdf`.

## Setup

```bash
pip install -r ../../requirements.txt
```

## Run

```bash
python f01.py
# or
streamlit run pdf2word.py
```
