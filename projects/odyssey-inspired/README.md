# Odyssey Inspired

Suno song-prompt research and prompt configs inspired by *The Odyssey* / ancient-Greek mythology themes, built with the `suno-song-creator` workflow (see the [suno-song-creator-plugin](../../suno-song-creator-plugin) at the repo root).

## Contents

- `ithaca-echoes/prompt.md` — full Suno prompt configuration (model params, genre/instrumentation/mood tags, structured lyrics-box arrangement, and research notes) for an instrumental cinematic track evoking a mythic homecoming voyage.

This folder holds prompt/config documents, not runnable code.
